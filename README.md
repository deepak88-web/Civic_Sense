# CivicSense

### Multilingual Civic Complaint Classification and Prioritization Using Attention-Based BiLSTM

CivicSense is an NLP-based application designed to classify and
prioritize civic complaints written in Hindi, English and Hinglish.

## Technologies

- Python
- TensorFlow / Keras
- BiLSTM with Attention
- FastAPI
- React.js
- MongoDB Atlas
- Microsoft Azure
